# 💰 即时薪资追踪器

一个沉浸式的实时薪资可视化工具，帮助你直观感受每一分钟的工作价值。

## ✨ 功能特点

- **实时收入追踪**：每秒更新今日已赚金额
- **精美视觉效果**：金色粒子动画、玻璃拟态设计
- **自定义配置**：支持设置月薪、工作时间、工作日、发薪日
- **智能计算**：自动计算每日工资、每分钟收入、本月累计
- **数据持久化**：配置自动保存到浏览器本地存储

## 🚀 快速开始

### 在线访问

通过 GitHub Pages 访问：https://max-vegetable.github.io/money-tracker

### 本地运行

直接用浏览器打开 `index.html` 即可，无需后端！

## ⚙️ 配置说明

1. **月薪**：输入你的税前月薪
2. **工作时间**：设置上班和下班时间
3. **工作日**：选择每周工作的日子
4. **发薪日**：设置每月发薪日期
